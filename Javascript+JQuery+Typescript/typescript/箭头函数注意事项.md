## 箭头函数注意事项

||
|---|
|返回对象 - 始终使用（）|
|使用 {} - 始终写return |
|对象方法 - 使用普通函数语法， 箭头函数非常合适回调，但不适合对象方法|
|可变参数 - 使用 ...args， 不要使用arguments， 箭头函数没有arguments|
|使用map()返回对象 - 再检查一次括号|
|异步箭头函数返回undefined|


```ts
// 1. 返回对象 - 始终使用（）
// ❌
const getUser = () => { name: "xxx"};      // getUser(); --> undefined
//✅
const getUser = () => ({ name: "xxx"});   // getUser(); --> {name: "xxx"}
// 2. 使用 {} - 始终写return + 使用map()返回对象 - 再检查一次括号
// ❌
const users = ["111", "222", "333"];
const result = user.map( name => { name: name})   // [undefined, undefined, undefined]
//✅
const result = user.map( name => ({ name: name}))   // [{name: "111"}, {name: "222"}, {name: "333"}]
// 3. 对象方法 - 使用普通函数语法
// ❌
const user = {
  name: "Tushar",
  greet: () => { console.log(this.name)}
}
user.greet()   // undefined
//✅
const user = {
  name: "Tushar",
  greet() { console.log(this.name)}
}
user.greet()   // Tushar
// 箭头函数没有自己的this，它会从外部作用域继承this
// 3. 可变参数 - 使用 ...args， 不要使用arguments， 箭头函数没有arguments
// ❌
const test = () => {
  console.log(args)
}
test(1,2,3)    // Uncaught ReferenceError
//✅
const test = (..args) => {
  console.log(args)
}
test(1,2,3)  // [1,2,3]
// 4. 异步箭头函数返回undefined
//✅
const fetchUser = async () => ({
  id: 1,
  name: "Tushar",
});
console.log(await fetchUser());
```
